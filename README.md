# Bank Marketing: AI-Assisted Data Analytics

An end-to-end analytics project to identify which bank customer segments subscribe to a term deposit, from raw data to an interactive Power BI dashboard.

## What I did
- Cleaned the dataset and ran exploratory data analysis (EDA) to find which customer segments subscribe to term deposits
- Built and compared four classifiers: Logistic Regression, Decision Tree, Random Forest and SVM
- Designed a 7-page interactive Power BI dashboard
- Summarized the findings in an AI-assisted insights report
- Presented the analysis in a recorded walkthrough
